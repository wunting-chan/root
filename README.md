# ting.directory

The root landing page retains the computer lab's original in-page entrance. The 3D art portfolio lives at `/arts/`, with its generated text version at `/arts/text/`. The independent academic site lives at `/research/`.

Run `npm run build:text` to regenerate the art text site and sitemap. Legacy HTML routes redirect to their new art URLs. External media URLs are unchanged. Legacy direct asset trees at `/media/` and `/projects/` are retained for inbound links.
